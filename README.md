
# File System Representation and Search Using BFS and DFS

## Objective
To represent a file system as a graph using an adjacency matrix and search for files using BFS and DFS algorithms.

## Technologies Used
- C Programming Language
- Graph Data Structure
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## Features
- Represents files and directories as graph nodes.
- Stores connections using an adjacency matrix.
- Displays BFS and DFS traversal orders.
- Reports whether the requested file is found.

## How to Run
Compile:
gcc main.c -o main

Run on Windows:
.\main.exe

## Sample Search
Starting node: Root
Target file: report.pdf

Result: File found using both BFS and DFS.
